This is a starter Logseq DB knowledge graph with built in, lightweight, ontology to get you started. 
- This ontology conforms to industry standard knowledge graph best practices and is designed to be LLM friendly and scalable.

# To Get Started
- Make sure you have Logseq DB: [Logseq DB - Beta Release 2.0.1 - GitHub](https://github.com/logseq/logseq/releases/tag/2.0.1)
- Download the *.edn file from this repository
- Install and open Logseq
- Use the ellipses, `...`, in the top right corner and go to `Import`
- Select EDN to DB graph
- Give your graph a personalized name
- (It might crash... it's still in Beta, it happens. If it does, restart Logseq)
- It should drop you on the Journals page with today's date
- Scroll down to the 1st August 2026 Journal entry 
- Click on the Welcome page!
